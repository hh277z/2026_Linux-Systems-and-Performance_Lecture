# 7주차 메모리 관찰 실습

Linux/glibc 또는 WSL2 Ubuntu에서 실행합니다. gcc, make, strace와 터미널 두 개가 필요합니다.

1. Lab7_instructions.docx를 읽습니다.
2. 이 폴더에서 make로 빌드합니다.
3. 안내서대로 터미널 A에서 실행하고 터미널 B에서 관찰합니다.
4. 각 단계의 관찰을 마친 뒤 Enter로 다음 단계로 진행합니다.

lab7_memory.c는 완성된 실습 예제이고 observe.sh는 원본 기록 저장용입니다. 과제용 도구나 실습 외의 코드는 필요하지 않습니다.
